# Bảng xếp hạng nhân vật — Bản chờ duyệt

File này dùng để bạn tự sắp xếp nhân vật trước khi triển khai trang Bảng Xếp Hạng.

## Cách chỉnh

- Thứ tự nhóm cố định: `UR+ → UR → SSR+ → SSR → SR → R → N`.
- Trong từng nhóm, dòng nằm trên có thứ hạng cao hơn dòng nằm dưới.
- Di chuyển cả dòng nhân vật khi thay đổi thứ tự, sau đó đánh lại số thứ tự cho liên tục.
- Giữ nguyên ID trong dấu `` ` ``, vì ID được dùng để nối với dữ liệu game.
- Mỗi nhân vật được đánh dấu bằng số thứ tự `#01`, `#02`... trong tier của mình.
- Thứ tự hiện tại chỉ là bản nháp theo catalog, chưa phải bảng đánh giá chính thức.
- Sau khi bạn chốt file này, dữ liệu mới được đồng bộ để triển khai giao diện.
