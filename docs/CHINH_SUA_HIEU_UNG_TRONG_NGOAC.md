# File chỉnh sửa thuật ngữ trong ngoặc vuông [] và ngoặc đơn ()

> **Hướng dẫn chỉnh sửa:**
> - File này tổng hợp tất cả các thuật ngữ trong ngoặc vuông **`[...]`** (Tên hiệu ứng, kĩ năng) và các cụm từ giải thích trong ngoặc đơn **`(...)`** của 177 nhân vật.
> - Điền bản dịch/chỉnh sửa của bạn vào cột **Tên / Nội dung Việt bạn chỉnh sửa**.
> - Đánh dấu `[x]` vào cột **Đã chốt** sau khi bạn sửa xong.
> - Sau khi sửa xong, báo lại Codex để cập nhật tự động toàn bộ ứng dụng và kiểm tra unit test.
